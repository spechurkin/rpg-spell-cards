# Карточки заклинаний

Ручной редактор карточек для НРИ на основе [Starfinder Cards](https://reverzz.github.io/starfinder-cards/) от reverzz.
Оформление вдохновлено карточками LSS.

Все поля свободные: уровень, название, действие (стоимость вместе с видом), дистанция, длительность, школа и компоненты.
Необязательные пустые поля не выводятся. Карточка из исходного форка оставлена как редактируемый пример.

Описание вводится в обычное текстовое поле без панели форматирования.
Поддерживаются `**жирный**`, `*курсив*`, `_курсив_`, `__подчёркнутый__`, `~~зачёркнутый~~`, `~зачёркнутый~`, код в
обратных кавычках, ссылки, заголовки, простые списки и цитаты. Горячие клавиши и синтаксис перечислены под описанием.
Это локальный формат обогащённого текста; Foundry VTT UUID, броски и системные директивы не исполняются. HTML
отображается текстом, ссылки разрешены только HTTP, HTTPS и mailto.

Изменения автоматически сохраняются в localStorage текущего браузера. Для переноса и резервной копии используйте
«Скачать JSON». «Открыть колоду» добавляет карточки из JSON, сохраняя текущие. Лимит: 300 карточек, 30 000 символов
описания, файл до 10 МБ. При недоступном хранилище интерфейс предлагает скачать JSON.

Печать: карточки 63 × 89 мм, сетка 3 × 3 на A4, поля 10 мм, между рядами 3 мм для резки,
между отдельными карточками по горизонтали не менее 0,5 мм.
Карточки размещаются слева направо. Одинарные карточки заполняют свободные места рядом со сдвоенными,
в том числе на предыдущих листах. Выберите масштаб 100% и отключите колонтитулы.
Длинное описание автоматически переносится на следующие карточки с сохранением форматирования и нумерацией частей.
Продолжение содержит только текст, без повторения названия и характеристик. Первые две части объединены
в двойную карточку с общей рамкой. Третья часть, если есть, стоит отдельно рядом с ней в том же ряду.
Более длинные заклинания разбиваются на группы по три части. Группа не разрывается между рядами
и листами. Размер текста можно менять ползунком. Если
сами характеристики занимают всю карточку, редактор
предлагает сократить их перед печатью.
